# 綜合除法能源工廠

三人同時上台、各區獨立闖關的繁體中文數學遊戲。每題由學生親自完成代入數、係數排列、綜合除法的所有乘加欄位，以及商式係數與餘式。

建議 GitHub 專案名稱：`synthetic-division-energy-factory`

## 開始使用

解壓縮下載檔，開啟 `index.html` 即可遊玩。`index.html`、`styles.css`、`math.js`、`app.js` 四個檔案要放在同一個資料夾。遊戲無須安裝套件或連線，沒有外部字型、圖片或程式庫依賴。

課堂上建議使用 Chrome 或 Edge，投放為 16:9，按遊戲右上角「全螢幕」或 F11。左、中、右各一位學生；可選座號或留空。每區可獨立開始、完成、換人，不必等待其他區。

## 學生操作

1. 選座號並按「啟動發電站」，也可先使用不限時示範。
2. 令除式等於 0，填入綜合除法右上角使用的數。例如除以 `x + 2`，應填 `−2`。
3. 按降冪排列填入所有係數；缺少的項也必須補 `0`。
4. 首項係數帶下後，依序完成「左下的數乘代入數」與「同欄相加」，直到整張表完成。
5. 依序填入商式的所有係數與餘式。商式次數比被除式少一次，底列最後一格是餘式。
6. 使用各區自己的數字鍵盤。`＋/−` 切換負號，`⌫` 刪除一個字元，「清除」清空輸入，「確認」提交。答錯可繼續重試。
7. 完成後會展示完整綜合除法、商式、餘式，以及「被除式＝除式×商式＋餘式」的驗算。

每次只會亮起目前要填的格子，所有欄位都由學生輸入。填完表格後，底列數字會保留，學生仍須自行整理商式係數與餘式。

若用實體鍵盤測試，先點擊要操作的區域，再用數字、負號、Backspace、Delete、Enter 輸入；大螢幕三人操作請使用各區的觸控鍵盤。

## 教師設定

| 項目 | 預設值 / 說明 |
| --- | --- |
| 二次 / 三次 / 四次多項式 | 各 1 題，可各設 0～10 題，至少共 1 題 |
| 難度順序 | 由二次到四次，可選混合順序 |
| 每題時間 | 240 秒；可選不限時或 60～600 秒的選項 |
| 每題求救卡 | 2 張，可設 0～3 張 |
| 逐步運算提示 | 預設開啟，可關閉；目前任務名稱仍會顯示 |
| 一般係數範圍 | −6～6；可選 ±3、±4、±6、±9 |
| 代入數絕對值上限 | 3，可設 1～5 |
| 額外安排缺項題機率 | 50%，可設 0%、25%、50%、75%、100% |
| 首項係數 | 預設 ±1、±2、±3，可固定為 1 |
| 除式為 x | 預設不出現，可開啟以練習代入數為 0 |
| 座號 | 預設 1～30，可設 1～99 範圍 |

二次題的係數最多為 ±4、代入數最多為 ±2。所有題目除式均為首項係數 1 的一次式 `x − c`，符合本版綜合除法流程。所有計算過程的乘積與底列數值控制在 ±150。

「額外安排缺項題機率」決定是否強制安排至少一個中間係數為 0；其餘題目的隨機係數也可能自然出現 0。

教師設定只套用到下一回合，不會改動其他學生正在進行的題目。開啟教師設定或玩法說明時，三區計時都暫停；關閉後繼續。

## 計分與紀錄

每題基本 100 分，每次答錯扣 3 分，基本分最低 20 分。每使用一張求救卡，基本分乘以 0.8，最後四捨五入。限時模式另加 `floor(20 × 剩餘秒數 ÷ 設定秒數)`，最多 20 分的時間獎勵。不限時模式沒有時間獎勵。

整題完成才計分；逾時會顯示完整解答，該題 0 分。每張求救卡顯示目前步驟的計算與答案，同一格只能使用一次，仍須自行輸入。示範練習可顯示分數，但不寫入課堂成績。

設定與最近 100 筆已完成回合的紀錄，儲存在目前瀏覽器的 localStorage。教師可下載含 UTF-8 BOM 的 CSV，用 Excel 開啟中文欄位。清除瀏覽器資料或更換裝置／網址後不會同步。成績會在最後一題按「查看本回合成果」後寫入；中途按「結束本區」不會留下成績。

## 放到 GitHub Pages

1. 在 GitHub 建立專案，建議命名 `synthetic-division-energy-factory`。
2. 將解壓後的檔案上傳到專案根目錄，確認根目錄有 `index.html`；不要把整個外層資料夾再套一層上傳。
3. 到 **Settings → Pages**，在 **Build and deployment** 選 **Deploy from a branch**。
4. Branch 選 **main**，資料夾選 **/(root)**，按 Save。
5. 等 GitHub 顯示 Pages 網址後開啟，即可加入你的教學遊戲中心。

如果專案已使用其他部署分支，改選實際上傳檔案的分支即可。本遊戲為純靜態網頁，不需要 Firebase 或伺服器。

## 程式檔案

- `index.html`：頁面與教師設定。
- `styles.css`：三區布局、觸控按鈕與能源工廠視覺。
- `math.js`：題目產生、綜合除法、商式與餘式、計分。
- `app.js`：各區狀態、計時、輸入、提示、成績與 CSV。
- `tests/math.test.cjs`：以 Node.js 執行的數學驗證。

下載版測試：`node tests/math.test.cjs`。開發原始碼版將靜態檔案放在 `dist/`，測試會自動選擇對應路徑。

遊戲支援個別觸控點選；實際能同時辨識的觸控點數與 Touchback，仍取決於顯示器及投放連線。桌面橫向畫面維持三欄；窄手機畫面改為逐區上下瀏覽。
